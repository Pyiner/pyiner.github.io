隐私政策

PTE WFD 听写（WFD FM）是一款无需注册账号的离线学习工具。完整的本地学习进度、逐句听写答案和原始评分详情、题库与翻译内容、音频、生词本、收藏及 WFD FM 播放状态不会上传。只有在你明确同意匿名统计后，App 才会另行上传与题目位置关联的开始/完成事件及分数区间，用于估算匿名学习深度；不会上传答案或内容。具体字段如下。

一、可选的匿名产品统计

只有在你点击“同意匿名统计”后，并且设备已登录且可使用 iCloud 时，App 才会通过 Apple CloudKit 向本 App 专属的 public database 写入以下六类产品交互事件：App 冷启动；开始某一道听写；提交某一道听写并得到分档成绩；首次触达免费题目上限；付费墙曝光；购买成功及商品类别。

事件参数只可能包含题目序号、成绩区间、付费墙触发方式和商品类别。我们不会上传题目或翻译内容、你的听写输入、原始分数、生词、收藏、具体 StoreKit 交易号或支付凭证。

这些数据只用于衡量学习漏斗、了解功能使用情况、评估免费额度与购买转化，并据此改进产品。我们不把它用于广告、营销、个性化推荐、信用判断或任何与本政策不一致的用途。

二、匿名 CloudKit 标识

CloudKit 会为当前 iCloud 用户在本 App 的 container 内生成一个匿名 user record ID，并自动把它记录为事件 record 的创建者。我们使用它区分不同匿名用户的学习深度，从而避免把“很多人各学一句”和“一个人学很多句”混为一谈。

该 ID 不包含姓名、邮箱、电话或 Apple 账户名；开发者不能由它反查你的真实 Apple ID，也不能把它用于另一个 App/container。我们不会把它与支持邮件、广告数据、通讯录或外部数据集连接，也不会尝试识别匿名用户。

如果你没有登录 iCloud、iCloud/CloudKit 不可用、没有同意或已经撤回，事件会直接丢弃。因此统计只覆盖同意且 CloudKit 可用的部分用户，存在系统性偏差。

三、Apple CloudKit

数据保存在开发者自己的 Apple CloudKit container 中，由 Apple 提供传输、存储、账户认证和运行日志服务。Apple 可能为提供 CloudKit 而处理必要的系统 metadata，例如操作时间、平台、操作类型、client OS 和匿名 container-specific CK User ID。我们没有引入友盟或其他第三方统计 SDK，不向第三方分析商、广告网络或数据经纪商共享记录。

有关 Apple 如何处理 iCloud 数据，请参阅 Apple 隐私政策。

四、不会采集的内容

本 App 的统计不会采集或使用 IDFA、IDFV、IMEI、MAC、OPENUDID、GUID、SIM IMSI、位置、通讯录、应用列表、运营商、剪贴板、广告数据或设备指纹。App 不展示广告，不进行跨 App 或跨网站追踪，也不请求 App Tracking Transparency 授权。

CloudKit 网络连接自然需要网络层处理 IP 地址，但本 App 不把 IP 写入 record、自建日志或用于位置推断；开发者的业务统计字段中没有 IP。

五、本地数据

学习进度、收藏、生词本和播放偏好保存在你的设备上，用于提供 App 功能。题库、音频与翻译均包含在 App 内，听写与 WFD FM 播放本身不需要网络请求，App 也不会录制或上传你的声音。卸载 App 后，本地数据会被系统删除。

六、你的选择

首次启动会显示克制的底部选择条，只有点击“同意匿名统计”才会启用统计；“暂不参与”不会限制听写、词典、WFD FM、购买或任何其他功能。选择会保存在设备本地，因此不会每次启动重复询问。

你可以随时从题库页顶部筛选菜单打开“隐私与数据”，查看本政策、开启统计或撤回同意。撤回后不会再发送新事件；撤回不影响已经保存在本机的学习内容。

七、保存、访问与删除

成功写入的匿名统计 record 最长保留 24 个月，之后删除或只保留无法回溯到单个匿名user record 的汇总结果。

如需访问、导出或删除此前的匿名 CloudKit 记录，请通过 支持页 联系开发者并注明“CloudKit 数据请求”。开发者会回复用于核对本 App container 匿名 user record 的步骤，并在核验后处理相应记录。由于 App 不收集姓名或邮箱，不能仅凭现实身份自动定位匿名记录。

八、儿童隐私

App 不会有意收集任何年龄用户的个人信息。

九、政策变更与联系

如果事件、用途、数据接收方或身份关联方式发生实质变化，我们会先更新本政策和 App Store 隐私标签；需要新增用途时会重新征得同意。不会把本次同意扩张为广告、追踪或新的内容采集授权。

如有疑问，请通过 GitHub 开发者主页 联系。
